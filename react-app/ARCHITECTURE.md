# Farma React Architecture

هذا التطبيق هو مسار التحويل التدريجي لنظام Farma. تظل النسخة القديمة في جذر المستودع وعلى فرع `main` حتى تكتمل مطابقة الوظائف واختبارها.

## Structure

```text
src/
  components/
    auth/            # عناصر تسجيل الدخول
    layout/          # Sidebar وTopbar وأي عناصر مشتركة
    notifications/   # جرس الإشعارات وصوت التنبيه
  config/            # الثوابت والتنقل وتسميات النظام
  lib/               # عملاء المكتبات، مثل Supabase
  pages/             # صفحة مستقلة لكل قسم وظيفي
  services/          # كل استعلامات وعمليات Supabase
```

## قواعد العمل

تُكتب استعلامات Supabase داخل `services` ولا تُوضع داخل مكونات العرض إلا عند الحاجة إلى استدعاء service واضح. تُستخدم المكونات المشتركة لكل ما يتكرر بين الصفحات، خصوصًا الترويسة، القائمة، الإشعارات، الجداول، النوافذ، ورسائل الخطأ. تُنقل كل صفحة من النظام القديم على حدة، مع الحفاظ على الصلاحيات وقواعد العمل الحالية قبل إزالة النسخة القديمة.

## الأداء

تستخدم الصفحات Pagination و`select` بأعمدة محددة، ولا تُحمّل مكتبات Excel أو الباركود إلا عند نقل الوظيفة التي تحتاجها. لا يُسمح بإعادة تحميل بيانات كبيرة بلا حد، ولا بتغيير بيانات الإنتاج أثناء اختبار الواجهة إلا من خلال عملية واضحة قابلة للمراجعة.

## Workflow

يتم العمل على فرع `react-migration`. بعد نقل كل قسم، يجب تشغيل `pnpm build` و`pnpm lint`، ثم مقارنة العمليات الأساسية مع النسخة القديمة قبل الدمج. لا يتم تغيير `main` أو مسار Vercel الإنتاجي إلا بعد اكتمال اختبار القسم ومراجعته.
